# FinanceTracker
Веб-приложение для учета личных финансов, разработанное на .NET 8 и Blazor Server.

## Стек технологий
* **Backend:** .NET 8, ASP.NET Core, Blazor Server
* **ORM & Database:** Entity Framework Core (Code First), SQLite
* **Infrastructure:** Docker, Docker Compose

## Как запустить проект (через Docker)
1. Убедитесь, что у вас установлен Docker Desktop.
2. Склонируйте репозиторий.
3. Откройте терминал в папке с файлом `docker-compose.yml`.
4. Выполните команду:
   ```bash
   docker-compose up -d --build

Перейдите в браузере по адресу http://localhost:8080.
